# Rust-ядро Fantasy Map Studio

Переносим расчётные системы из JS на Rust. Решения владельца: переносим ядро расчётов + лёгкая оболочка (Tauri вместо Electron, позже); миры одного seed в Rust могут отличаться от JS, проверки — на инвариантах, а не на хешах.

## Состояние
- `fms-core/src/tectonic.rs` — порт `src/sphere-tectonic-history.js` (коммит 4c6be35): коллаж кратонов, плиты суши и океана, субдукция и дуги, возраст дна, горячие точки, силы, затопления, эрозия, уровень моря.
- `fms-core/src/rng.rs` — тот же генератор (mulberry32 + FNV-1a) и гладкий шум.
- `cargo test --release` (в `rust/`) — 7 тестов инвариантов; `cargo run --release --example gen -- <seed> [w]` — быстрый прогон.
- Поворот точек считается в нескольких потоках (результат от числа потоков не зависит).

## Не сделано
- Порт основного генератора `src/generator.js` (плиты, гидрология, климат, биомы, берега), политика, поселения и пр.
- Оболочка Tauri и привязка интерфейса; сборка под macOS не проверялась.
- Дальнейшее ускорение (растекание коры, дуги): сейчас ≈6–8 с на мир 360×180 на 2 ядрах против ≈14 с в JS.
