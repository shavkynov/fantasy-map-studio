FANTASY MAP STUDIO

Генератор фэнтези-карт для авторов и мастеров игр. Строит мир с нуля: тектонические
плиты, горные цепи, рельеф, реки, леса, государства, города и дороги, а затем рисует
карту в стиле старых книжных атласов. Работает без интернета.


ВОЗМОЖНОСТИ

- Генерация: одно и то же зерно (seed) всегда даёт одну и ту же карту. Число материков,
  размер мира, древние эпохи, вулканы, горячие точки, расколы и каньоны.
- Рельеф и природа: горы и вулканы, реки со слиянием, леса по климату (дождевая тень
  за хребтами), приливы, морские течения.
- Суша: кисть для правки берегов, мазки накапливаются в очереди и применяются разом;
  пересчитывается только изменённая область.
- Государства: столицы, рост территорий с учётом гор и рек, границы по рельефу или
  нарисованные вручную, подписи по дуге.
- Города и дороги: расстановка по плодородию, воде, обороне и ресурсам; культуры
  (реалистичная, горцы, лесные, мореходы, степняки); дороги, мосты, ручная правка.
- Карта города: планировка по дорогам, рекам и морю, свои объекты, новый вариант.
- Стили: «Сепия» и «Ч/Б». Интерфейс на русском и английском.
- Экспорт: PNG. Мир сохраняется в файл и открывается снова.
- Связь с Fantasy Calendar: раздел «Для календаря» выгружает воду, города с широтами
  и параметры планеты в файл world-exchange.


УСТАНОВКА

Готовые установщики находятся на странице Releases этого репозитория:

  macOS (Apple Silicon)  FantasyMapStudio-<версия>-mac-arm64.dmg
  macOS (Intel)          FantasyMapStudio-<версия>-mac-intel.dmg
  Windows 10/11          FantasyMapStudio-Setup-<версия>.exe
  Linux (x64)            FantasyMapStudio-<версия>-linux-x64.AppImage

Установщики не подписаны, поэтому при первом запуске система покажет предупреждение:

  macOS:   откройте программу через контекстное меню «Открыть» и подтвердите запуск.
  Windows: в окне SmartScreen нажмите «Подробнее», затем «Выполнить в любом случае».
  Linux:   сделайте файл исполняемым (chmod +x FantasyMapStudio-*.AppImage) и запустите его.


СБОРКА ИЗ ИСХОДНИКОВ

Нужен Node.js 20 или новее.

  npm install
  npm run check        проверка кода
  npm start            запуск
  npm run dist:dmg     установщик для macOS (Apple Silicon)
  npm run dist:dmg-intel  установщик для macOS (Intel)
  npm run dist:win     установщик для Windows
  npm run dist:linux   AppImage для Linux

Установщики для всех систем собирает GitHub: вкладка Actions, workflow «Проверка и
сборка», кнопка Run workflow, либо метка версии (git tag v0.90.0 и git push --tags),
тогда файлы сразу попадут в Releases.

Без Electron карту можно открыть и в браузере: двойной клик по src/index.html
(лучше в Chrome).


СТРУКТУРА

  main.js, preload.js   окно Electron, меню, обмен с интерфейсом
  src/                  генератор мира, государства, города, рисование, интерфейс
  scripts/              запуск, проверка, выпуск версии
  tools/                проверки генератора и снимки экрана для разработки
  build/                иконки приложения
