This package adds the display library, compatible replay trace forwarding and its tests. API / CONTRACT
RainfallRunoffDisplay.create(d) takes water, view, doc, win, routing, getContext(frame), getSurface(), getVisible(), getThreshold(), isLocked(). Returns compose(frame,normal), refreshAll(), attach(), dispose().
compose finds completed record by exact frame identity and validates trace frame/result/surface identities. It obtains field and drainage from getContext for THAT frame, not selectors or another pane. Context helper validates private trace ownership. Cache is WeakMap keyed by trace; caller must keep returned states immutable.
Only regional surface is supported. Disabled/Material/missing data returns original normal object. Positive finite threshold is a rate in relative-height*steradian/model-time, not catchment area or m3/s. Cyan pixel alpha uses a logarithmic scale relative to the maximum in this result; no inter-pane calibrated color scale.
Only positive dry-generated flow above threshold is painted. No paths are extended through initially wet cells. No release of stored water, spill discharge or river speed is inferred. Input pixel array is copied, not mutated; main-canvas integration would include this layer in PNG, but native PNG is not tested here.
compose does not write DOM. It may paint the last completed record while a new run is busy, or a synchronously staged project record before viewer publication. The readout explicitly waits for busy/project locks and checks the live pane frame. It must not claim an incomplete run is finished.
Errors in diagnosis/threshold return base pixels and become readout warnings. If the readout backend itself fails, lifecycle update attempts are suppressed so original action errors/return values survive. Public refreshAll/dispose can still throw with a broken backend; no unconditional DOM transaction is promised.
