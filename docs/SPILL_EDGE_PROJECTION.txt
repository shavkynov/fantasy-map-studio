SPILL EDGE PROJECTION — exact-context saddle crossings, not live river UI
Baseline: 1e9c3065f7eec5cbdc5dcf00948ca545dbf17347.

API
SpillEdgeProjection.create(field,hierarchy,frame,Fill) returns {fill,project(frame,redistribution),projectJournal(frame,journal)}. Its fill proxy forwards the same arguments to the injected Fill exactly once and returns the SAME numerical result object. It only records a projection when that actual result has routingTrace. Explicit tracking without a returned journal is rejected. No second solve is used to reconstruct an earlier event.
Pass proxy.fill into the numerical factory for these exact field/hierarchy references. Results and journals are recorded in private WeakMaps only after successful validation. project/projectJournal require the exact frame and an exact recorded object, reject clones/other contexts, and return structuredClone copies so external edits cannot poison the projection cache. Solver snapshots must remain immutable after capture; the cache is a validated snapshot, not continuous tamper detection of mutable result contents.

VALIDATION
Context copies land/height/area/cellBasin/edge metadata. Frame mask must match. Every spatial edge must have in-range cells, the declared endpoint basins, mutual adjacency according to field.neighbors and a level matching max(endpoint land heights, external water level zero). Stored fromCell/toCell order need not agree with a/b or with actual flow.
Each journal is replayed with disjoint-set membership and active per-call nodes. Checks include source inventories, nonnegative volumes, unique sequential merge nodes, no retired-node reuse, event-edge membership and actual transfer direction. Merge changes membership but emits NO flow segment. Transfer/boundary events become oriented {kind,edge,fromCell,toCell,volume} saddle crossings.
Final journal inventories, physical pool membership/poolByBasin, depth*area versus basinStorage, operation/transfer/merge counts and boundary export must agree within 1e-10 scaled inventory tolerance. Guards reject changed field dimensions/masks/land heights/areas/basin labels and edge metadata or a replaced neighbors function. Callers must still keep neighbor closure data and geometry immutable; this is not cryptographic engine authentication or a proof that a supplied hierarchy is globally complete.

MEANING / INTEGRATION LIMITS
Output contains saddle crossings, NOT an inferred path inside a pool, a raster river line, velocity, residence time or calibrated discharge. Volumes are relative-height*steradian inventories. grossInternalTransferVolume can count water moved over multiple edges; it is not net input/export and must not be added again to the water ledger. A seam crossing stays a cell pair; future rendering must wrap it rather than draw a long line across the map.
This captures individual Fill results/journals, NOT the outer completed Surface/atmosphere run. Live record identity, cancellation, locks, replay and rollback still need their own integration. Atmospheric factories copy geometry: bind the adapter to their actual surface field/hierarchy, not to a lookalike clone. Geometry guards scan cells/edges; dense-map overhead is unmeasured.
No existing application, numerical module, page, build ID or recipe/ENGINE is changed by this package. .14 does not load this module and needs no rebuild. Next: use the adapter in actual step orchestration, retain both inflow/recession journal provenance, and only then enable honest spill markers or routes in the UI.
