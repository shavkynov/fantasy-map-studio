# Тестовый прототип трёх блоков v0.1

Ветка: feature/natural-world-v3. Основной генератор и версия приложения не меняются.

## Запуск на Mac из ZIP

Распаковать ZIP ветки и запустить build-mac.command. В установленном приложении: меню «Прототип → Три блока (эксперимент)», либо Cmd+Shift+3. Файлы src включены существующим build.files. Сам DMG здесь не собран; Mac/Electron UI acceptance не подтверждена.

Проверка без Electron: node tools/three-block-prototype-test.cjs. Новых npm-зависимостей нет.

## Проверено при подготовке

JavaScript-ядро выполнено под Node: все 41 стадии 0…2° на 360×180 прошли; 0°, 0.05°, 0.25°, 1°, 2° дополнительно прошли на 720×360. Обратный -2° контроль отклонён: 817 континентальных перекрытий. SHA-256 исходных меток проверяется перед запуском; blob fixture 8de969d6c68157ce9a87678666f721b2714abe3e. В renderer используется DecompressionStream и Web Crypto; реальный Electron/Mac запуск ещё требует проверки.

## Ограничения

Исходный аналитический разрез локально исправлен явно. Старые области поворачиваются напрямую, без последовательного растрового переноса. Приоритет областей задан, а не выведен из динамики субдукции. Новая кора — геометрическая область текущего разрыва, без переноса от рождения и без возраста. Площади оценены растровой сферической квадратурой. Это JS-перенос ограниченного сценария, не архив прежних Python-стендов и не полный сценарий K6. Полная история планеты, непрерывная проверка тройных сочленений, geologicalRealismAccepted, visualAccepted, appIntegrated acceptance и movingK6StageAccepted не подтверждены. docs/evidence/CURRENT.json не изменяется.
