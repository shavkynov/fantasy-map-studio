Core.create(field,hierarchy,fill,{trackEvaporation:true}) optionally adds evaporationByCell to each ADVANCE result, in inventory units (relative-depth*steradian per step, NOT a rate). Ocean entries zero. Allocation follows the existing frozen POST-INFLOW wet mask, cell E*area rates, pool losses and recession splits; seepage excluded. Sum checked against stepStats.evapTotal. This is location bookkeeping for the existing approximate loss scheme, not new physically calibrated evaporation; it can retain frozen-step rates on cells drying during a step. Default tracking false, no extra result array.
Moisture context now has injectSurfaceVapor(state,cellInventory). Pure injection AFTER rain/surface loss, on land only. It returns a new context-bound atmosphere state, adds surfaceSourceTotal to its ledger, preserves the completed precipitation arrays/diagnostics and records surfaceVaporInjected. No transport or new rain during injection; returned vapor can move/rain on NEXT advance. Invalid amounts, ocean deposition, foreign context and imbalanced source rejected. Atmospheric balance includes the injected source. Existing no-injection path retains old state shape/values in tested default comparisons.
Join.create(field,hierarchy,Moisture,Core,Fill,{returnEvaporation:true}) enables feedback. Order: atmosphere advance -> surface advance with that rain only -> return actual tracked surface evaporation to the SAME grid cells in atmosphere. Cumulative returnedEvapTotal must equal surface evapTotal. Combined ledger retains surfaceEvapTotal as INTERNAL-transfer diagnostic, adds returnedEvapTotal and surfaceEvapSinkTotal=0, and excludes that evaporation from external sinks. With default returnEvaporation false, old one-way behavior and old combined ledger shape remain. Installed UI .9 does not pass this flag and will not silently enable feedback.
Global identity with feedback: initial + prescribed oceanSource = atmosphereStored + surfaceStored + rainOcean + nonRunoff + surfaceBoundary + surfaceEvapSink(0) + surfaceSeep + residual. Returned evaporation is neither a second source to this global ledger nor an additional sink. Ocean reservoir still external/infinite. Non-runoff and seepage not groundwater storage; ocean rain and boundary discharge remain sinks. No whole-planet reservoir closure, energy, temperature, pressure, physical circulation, seasons or orographic rain. Same relative units/arbitrary time, not years or m3. End-of-step return is operator splitting, not synchronous substeps or timestep convergence.
