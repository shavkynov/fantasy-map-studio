# Четыре блока — два эпизода

База: 927d00a9eed1e5f4fd372212c6e1d64e11174de5.
Меню «Прототип → Четыре блока — два эпизода», CmdOrCtrl+Shift+4. Старый просмотр и CmdOrCtrl+Shift+3 сохранены. Сборка: build-mac.command.

Восток неподвижен на 2° первого эпизода; запад [2] и [3,6] вращается на -phi/2 и +phi/2. История хранит эпизод и угол рождения, не складывает углы разных осей. Континентальный конфликт останавливает расчёт. Сетка просмотра и истории 180×90, кэш максимум три стадии, отмена устаревшего поля, без автопроигрывания. PNG использует существующий preload API.

JS-кандидат проверен на 245 точках: 229 сохраняют происхождение, 16 теряют владельца и замещаются старым материалом. Геометрия: шесть стадий 360×180. Полное поле 180×90 на 2°: 53 точки первого рождения и 68 второго. База тестов локально переписана из репозитория с проверенной исходной маской, не побайтовая копия всего модуля. UI и меню проверены только с имитацией DOM/Electron, не настоящим renderer. Mac этой версии не проверен. Конечное сканирование не доказывает отсутствие коротких событий; модель кинематическая, не физическая субдукция.
