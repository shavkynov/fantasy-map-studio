Dependencies: recipe.decode/encode (ABProjectRecipe), api.openWorld/saveWorld, capture(), replay(value,control), stage(candidate), setLocked(boolean), optional onStatus(event).
Caller adapts recipe.replay dependencies and forwards control.cancelled/onProgress. capture must use actual completed records/view. This test does not exercise the real recipe.

open locks before the dialog, decodes before replay, stages only a completed candidate, checks cancellation before publication and requires synchronous commit. Parallel open/save returns status busy. Cancellation invalidates the operation but keeps the lock until outstanding dialog/replay/staging resolves. It does not close the native dialog or interrupt synchronous numerical work. Save cannot be cancelled by cancel(): native save may already write the file.

stage must be detached and must clean up its own partial work if it throws. It returns {commit,rollback}. commit publishes BOTH panes synchronously; rollback must synchronously restore ALL prior state, pixels, controls and caches if commit throws, or discard staging if cancelled before commit. The session only invokes this contract; a real viewer adapter is NOT implemented here. Async commit is rejected, but the session cannot stop side effects scheduled by an invalid adapter. setLocked must reliably lock conflicting controls and restore readiness on unlock; unlock/rollback failures propagate and are not proof of old-scene preservation. Observer exceptions are ignored and cannot change transaction success.

open returns status opened/cancelled/busy. save returns saved/cancelled/busy. Errors propagate; lock release is attempted in finally. save captures/encodes completed state before awaiting the save dialog.
