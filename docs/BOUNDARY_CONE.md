# Numerical initial-boundary cone

Run node tools/world-boundary-cone.cjs --k4-02; echo "exit_code=$?". This convenience path uses the existing checksummed K4 fixture and existing edges extractor. No copying of old JSON into a new ZIP is needed. Alternatively pass a boundary-report JSON path (time=0, pair=[a,b], rows or cases[*].rows containing unit point/normal vectors). The solver is pair-independent; a unit case uses pair [5,9]. The convenience extractor remains the existing special 0–2 tool. Optional --unit-only. Node built-ins only; no SciPy, Python or npm dependency required on the user's Mac.

Constraints are a_i dot d >=0 with a_i=normalize(point cross normal), d=relative initial angular velocity. Any nonzero solution can be rescaled so its maximum absolute coordinate is1. Therefore test six cube faces d_j=+/-1 with other coordinates in[-1,1]. Each face is a 2D square clipped by halfplanes. Clipping adds1e-12 to each normalized inequality as numerical slack. Candidate coordinates are rechecked; minimum dot >=-1e-9 is reported as candidate-within-tolerance, not exact feasibility. Nonempty but unverifiable remnants produce inconclusive-numerics. Six empty expanded slices produce numerical-zero-cone. All operations are floating-point, not interval/exact arithmetic. Input has a 10000-row resource limit.

For a zero-cone result, a separate bounded deterministic search (fixed LCG seed, at most20000 quadruples) tries to find four positively weighted constraint rows summing to zero and spanning3D. Weights >1e-6, residual/sum error <1e-10 and a rank3 minor >1e-7 are required. A certificate may be null even for a zero cone (four-row certificates are not universal); absence is not treated as an independent certificate. Positive weights plus full span would force d=0 in exact arithmetic. Residuals are saved so this remains an inspectable numerical certificate, not a formal proof or geometry acceptance. No witness is automatically applied as a motion.

Units cover unconstrained/halfspace/plane/orthant feasible directions, opposing coordinate constraints, tetrahedral zero cone and certificate, row-order variation, unchanged inputs, malformed vectors/normals/time and non-K4 pair metadata. No synthetic project masks or fixtures.
