SPILL STEP CAPTURE — actual outer-step provenance, not UI activation
Baseline: d40d38567ff1d5af1d46637ec2c654ef10ee298d.

API
SpillStepCapture.create(field,hierarchy,frame,{Surface,Fill,Projection,Join,Moisture}) returns factories surface({trackEvaporation?}) and atmosphere({returnEvaporation?}). Options accept only the named boolean fields. Capture is an explicit opt-in factory; it always enables trackRouting on its actual surface model. Existing default numerical factories are untouched.
Returned model preserves empty/metadata/advance and adds spillStep(frame,result). advance calls the original model once, validates both journals and phase budgets, stores derived projections in a private WeakMap keyed by that exact returned outer result, and returns the same result object. spillStep rejects empty/foreign/cloned results and other frame identities, and returns a structuredClone copy. Supplied numerical dependencies and immutable snapshot/geometry contracts remain trusted; this is not cryptographic engine authentication.

ACTUAL ATMOSPHERIC GEOMETRY
Join copies field and hierarchy before constructing Surface. The adapter intercepts that Surface factory, uses its actual f/H and passes a projection-bound Fill into the actual numerical Surface. If copied f lacks neighbors, a new surface-field wrapper shares the copied arrays and adds a neighbor function bound to the original immutable topology. Projection and Surface receive the SAME actual augmented field/H; no lookalike geometry is substituted after calculation. The Join moisture field remains unmodified. Multiple/unexpected surface-factory calls are rejected.
The real Join still performs atmosphere advance, Surface advance and optional end-step vapor injection. Captured projections belong to returned combined.water; acceptedSurfaceInput is checked after the outer result returns. No second atmosphere, Surface or Fill calculation reconstructs diagnostics.

BUDGETS / MEANING
Inflow initial inventory equals pre-step stored water plus accepted input. Recession initial inventory equals inflow stored inventory minus actual evaporation/seepage. Both boundary exports sum to actual stepStats.exported; final projected storage matches the surface ledger. Tolerance is scaled 1e-10, permitting only rounding-sized negative expected remainders, not negative physical inventories.
spillStep returns dt, combined, separate inflow/recession projections and scalar budget. Values are inventories, not calibrated river discharge. Merges are not flow segments; no routes through pools are invented. Empty states have no completed-step projection. Failed validation does not register a new outer result; prior recorded results remain available. This does not make a mutating third-party solver transactional.

STATUS
No controller, live record, replay/adoption adapter, page, version/build ID, numerical source, forcing defaults or recipe/ENGINE is changed. .14 does not load this module and needs no rebuild. Caller still must publish capture/model/result together only after a whole run succeeds, retain old completed data on cancel/error, clear on reset/new geometry, and reconstruct captures during project replay. Those lifecycle paths are NOT implemented or tested by this package.
Capture currently validates/records EVERY advance on these opt-in models, not just step 20. WeakMaps avoid retaining unrelated result histories, but scans/copies and journal allocations add overhead; real dense-map performance is unmeasured. Do not silently enable this in the UI without that evaluation.
