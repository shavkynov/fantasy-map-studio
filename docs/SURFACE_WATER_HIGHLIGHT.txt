SurfaceWaterHighlight.mask(catalog,id) -> {w,h,pixels,cellCount,boundaryCellCount}. Validates Int32 label dimensions/range and selected local ID, returns fresh transparent RGBA. Selected cells have pale yellow fill; selected cells sharing an edge with another label/dry/ocean get a stronger yellow border. Longitude periodic; no artificial north/south boundary is added at the pole points. This is a one-raster-cell display outline, not a new shoreline/physical water calculation. Inputs unchanged; no geographical names or persistence.

attach({doc,canvases:[A,B]}) -> show(pane,catalog,id), clear(pane), dispose(). Wraps each original canvas in a relative div and adds a same-resolution absolute overlay, CSS width/height 100%, pixelated, pointer-events:none, aria-hidden. Original canvas identity, onclick and toBlob are not changed; only overlay getContext is used. Normal PNG export still targets the original map canvas and therefore excludes this interaction layer; actual native PNG behavior remains untested. Browser CSS supplies responsive alignment; native layout/zoom is not established by fake style-string assertions.

show uses a one-selection-per-pane identity cache and skips unchanged catalog/id draws. Catalogs/labels are assumed immutable. A different invalid selection clears the prior overlay before propagating its error. clear releases selection/cache and only clears overlay pixels. Pane state is independent. Duplicate attachment is rejected; partial creation/mounting is cleaned up where DOM remains usable. dispose is idempotent, returns original canvases before their wrappers, removes own overlay and empty wrapper, preserves foreign children/later canvas moves rather than deleting them. Broken DOM/canvas backends can still prevent cleanup.
