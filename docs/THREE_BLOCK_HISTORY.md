# История материала: новый кандидат

База: feature/natural-world-v3, c7569d5f10c0d867c50b95b473058542b642095d.
Это новая реализация по переносу, не восстановленный оригинал v0.2.

Запуск: build-mac.command; меню «Прототип → Три блока (эксперимент)», Cmd+Shift+3; слой «История новой коры».
Тест из корня: node tools/three-block-history-test.cjs src/three-block-prototype.js

История рассчитывается по обратной траектории текущего владельца с 64 интервалами, вход уточняется до 1e-9 градуса. Исходный материал после выхода не воскресает. Возраст нового материала выражен в параметре движения, старому океану и континентам возраст не назначается. Найденная историческая потеря континентального материала останавливает расчёт.

Конечное сканирование может пропустить короткие события. Модель не является полной физической симуляцией, консервативной моделью коры или решением динамики тройных сочленений.

Node проверен с настоящей маской SHA-256 d4faef01c8ab64447c04171c36211426374b9728a257c72e3cfc137f73b58947 на 360×180 для 0, 0.05, 1, 2°. Геометрия сравнивалась с переписанной из ответа GitHub-копией исходного ядра; байтовая идентичность всей исходной копии не сертифицирована.
UI проверен только DOM-stub с нативным Node-ядром. Настоящий renderer и Mac не проверены.
