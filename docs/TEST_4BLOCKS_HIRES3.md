# TEST 4blocks-hires3

База: 97021f3041d75357f7bb7a0c923a0512f3a44adf. Ветка feature/natural-world-v3; main не меняется. Версия установщика и плашки: 0.89.0-test.4blocks.3, buildId 4blocks-hires3.

Геометрия 720×360, история — отдельные пробы 180×90, не растянутое подробное поле. Маркеры не закрашивают сушу; проба скрывается при несовпадении владельца у границ. Инспектор рассчитывает историю в координате нажатия. PNG 720×360. Геологические ядра, настройки планеты и CURRENT.json не меняются. Счётчик эпох и календарь остаются отключёнными.

JS-ядро четырёх блоков побайтово проверено по Git blob 49a13395f2e90386f6fdd29cccdf44b78e1fcc5a. На 720×360 прошли стадии 0, .05, .25, .5, 1, 2° без sampled континентальных конфликтов. В нуле 0 несовпадений родительских областей. Базовый трёхблочный API для этого запуска — локально переписанные функции с проверенной маской, не полный оригинальный модуль. Node: примерно 0.6–0.8 с на кадр; это не обещание скорости на Mac.

Композиция/DOM: проверены защита суши, пропуск конфликтующих проб, инспектор, LRU максимум 3, отмена, PNG API. Настоящий renderer/Mac и DMG этой версии не проверены и не собраны. Полная история на 720×360 не вычисляется. Возраст старой коры не назначается, углы эпизодов не складываются; конечное сканирование не является непрерывным сертификатом.

Сборка из ZIP: /bin/bash ./build-mac.command. Запустить Fantasy Map Studio TEST, проверить плашку 4blocks-hires3 и открыть четыре блока. Тест viewer: node tools/four-block-viewer-test.cjs src/four-block-viewer.js
