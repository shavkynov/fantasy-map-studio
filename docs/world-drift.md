# Task 3: canonical fragments on the sphere

Standalone world-drift.js depends on world-domain.js and consumes an existing v4 source mask/regions. It does NOT replace world-v4.js, the atlas, climate or reference gallery.

fromSource(source,options) embeds canonical u as longitude and v=(1-z)/2 (cylindrical equal-area), so each source cell has equal spherical area. This changes the former planar appearance once, consistently for all pieces; it preserves source labels/shared provenance, not planar lengths. Options: radiusKm and optional motions [{axis,rate,spin}] per fragment. Default motions convert legacy tx/ty/spin into spherical kinematics, not force-driven tectonics. Time is dimensionless.

API: sourcePoint(u,v), point(id,u,v,t), restore(id,point,t), sourceIndex(point), pose(id,t), snapshot(t,{width:480,height:240,centralMeridian:0}), sourceLabels(). Negative time is allowed. All snapshots query original geometry, never a resampled previous image. Inputs are not mutated; public fragment descriptors are frozen.

Snapshots inverse-sample the sphere, avoiding display-frame clipping. owner=-1 is ocean, owner>=0 is one fragment, owner=-2 is collision; ambiguous sourceIndex=-1. coverage retains hit counts. Source area is exact/invariant; raster areas are approximate. Overlapping pieces reduce union footprint, which is NOT accepted as newly created ocean. validSampledGeometry only tests sampled overlap, not continuous collision freedom. Later default states do overlap: these are invalid candidates, not finished maps. No automatic packing, collision resolution, subduction or ocean-state selection is implemented. Polygon/vector export, geology transfer and terrain/climate recomputation are outside this change.

Run node tools/world-drift-test.cjs. Local checks: five frozen canonical masks verified by SHA, 25 snapshots, 2940 inverse provenance checks, area sampling tolerance, unchanged source labels, uniform full-turn raster equality and uniform polar motion. Max observed relative per-fragment raster area error at 360x180 was about 0.565%. Local geometry functions were extracted from published sourceWorld without unused SDF construction; canonical hashes match the committed baseline. world-domain.js was copied byte-identically. The committed test imports actual repository APIs. No real geology, climate, aesthetics or browser correctness is claimed.
