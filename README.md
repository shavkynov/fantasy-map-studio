# Fantasy Map Studio — физическое ядро планеты и мира

Ядро генерации фэнтези-миров на Rust (нулевые внешние зависимости в `fms-core`), где геология, рельеф, океаны, климат, реки, биомы, ресурсы, города, торговые пути и границы государств подчинены единой причинной физике реального мира.

## Модули `fms-core`

- `tectonic` — сферическая тектоника литосферных плит: наследственные древние и молодые швы столкновений (`suture`), раскол континентов по швам и над плюмами, лагранжевы континентальные рифты и вулканические провинции, глубоководные желоба субдукции, упругие предгорные прогибы, изостазия Эйри, тепловое погружение дна и сохранение объёма океана.
- `currents` — сферический решатель океанических течений (уравнение Стоммела `r∇²ψ + ∂ψ/∂λ = G(φ)` с учётом скорости вращения планеты `solve_with_rotation`), западная интенсификация и прибрежный теплоперенос.
- `climate` — сезонные поля температуры (январь/июль) с настройкой наклона оси, инсоляции и скорости вращения (`ClimateParams`), термические муссоны, сезонный сдвиг штормовых поясов, 2D-полулагранжев перенос влаги с рециклингом с суши и дождевой тенью, испаряемость (Holdridge PET), индекс аридности, снег и ледники.
- `erosion` — сопряжённая склоновая диффузия, флювиальная и ледниковая эрозия (неявный решатель FastScape), бездамбовое отложение аллювия в котловинах/предгорьях, наращивание речных дельт и сохранение объёма воды.
- `hydrology` — открытый океан, Priority-Flood заполнение впадин, стационарный водный баланс пресных и бессточных солёных озёр (с вычетом испарения) и солончаков, сезонный сток (`discharge_jan_m3s` / `discharge_jul_m3s`) со снеготаянием, пересыхающие русла (`is_wadi`), предгорные оазисы (`is_oasis`), потери пустынных рек, порядок Стрелера, дерево рек с режимами (`FlowRegime`) и типы берегов (включая ледниковые фьорды).
- `biomes` — коренные породы (`Bedrock`), плодородие почв (`soil_fertility`) и физическая классификация 19 биомов планеты.
- `geography` — выделение материков, островов и архипелагов, окраинных морей, заливов, проливов и перешейков, озёр со связями впадающих и вытекающей рек, горных хребтов, перевалов и природных макрорегионов.
- `resources` — закономерные поля железных и медно-золотоносных руд, самоцветов, угля, нефти/газа, соли, строевого леса, прибрежных апвеллинговых рыбных промыслов и дискретных месторождений.
- `civilization` — пригодность территории и хозяйственные уклады, диффузия культур с индексом изоляции, размещение городов и столиц, сухопутные/речные/морские торговые пути и естественные границы государств (с учётом рельефа и культурных рубежей).
- `toponymy` — процедурная русскоязычная топонимика, порождающая согласованные названия государств, городов, культур, материков, архипелагов, заливов, перешейков, хребтов, перевалов, озёр, рек и регионов.
- `planet` — единый связанный конвейер `planet::generate` и `planet::generate_with_options` (`PlanetOptions`).
- `region` — многомасштабный региональный зум (`2..=16×`) с бесшовным переходом через меридиан ±180°, переносом стока граничных глобальных рек, локальной эрозией FastScape, детальной гидрологией и привязкой поселений.
- `grid` — равнопромежуточная сферическая сетка с замыканием долготы `0 ↔ w - 1`, геодезические расстояния и операторы поля.
- `rng` — детерминированный ГПСЧ и трёхмерный сферический шум.

## Проверка и запуск

```bash
cargo test --release
cargo build --release --examples
cargo run --release --example planet -- a 360
cargo run --release --example region -- a 6
cargo run --release --example gen -- a 360
cargo run --release --example sea
```
