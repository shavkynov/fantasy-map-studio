# Fantasy Map Studio

Физически достоверный генератор фэнтези-миров и картографический рендерер на Rust (без внешних крейт-зависимостей в workspace).

## Крейты workspace

### `fms-core` — физическое ядро планеты и мира
- `tectonic` — сферическая тектоника литосферных плит: наследственные древние и молодые швы столкновений (`suture`), раскол континентов, лагранжевы рифты и вулканические провинции, желоба субдукции, упругие предгорные прогибы, изостазия Эйри и сохранение объёма океана.
- `currents` — сферический решатель океанических течений (уравнение Стоммела `r∇²ψ + ∂ψ/∂λ = G(φ)` с учётом скорости вращения `solve_with_rotation`).
- `climate` — сезонные поля температуры (январь/июль), `ClimateParams`, термические муссоны, 2D-полулагранжев перенос влаги с рециклингом и дождевой тенью, Holdridge PET, индекс аридности, снег и ледники.
- `erosion` — склоновая диффузия, флювиальная и ледниковая эрозия (неявный решатель FastScape), отложение аллювия и наращивание дельт.
- `hydrology` — океан, Priority-Flood, водный баланс пресных/солёных озёр и солончаков, сезонный сток (`discharge_jan_m3s` / `discharge_jul_m3s`), пересыхающие русла (`is_wadi`), оазисы, порядок Стрелера и типы берегов.
- `biomes`, `geography`, `resources`, `civilization`, `toponymy`, `planet`, `region` — 19 биомов, природные объекты и связи озёр/рек, месторождения ресурсов, культуры, города, торговые пути, границы держав, русскоязычная топонимика и бесшовный региональный зум `2..=16×`.

### `fms-render` — иллюстрированный рендерер атласов (PNG и многослойный SVG)
- Встроенный пакет иллюстрированных спрайтов (`fms-render/assets/`): 9 горных массивов, 12 лиственных/хвойных/осенних деревьев, соборные столицы, города, порты с маяком, замки, башни, деревянные мосты, холмы, 8-лучевая роза ветров и бесшовная фактура акварельной бумаги.
- Два встроенных стиля без разрезания континентов (изотропная проекция Паттерсона):
  - `Style::Expedition` — **Экспедиционный атлас**: архивная палитра, физические тёплые и холодные течения Стоммела, полярный паковый лёд, пунктирно-точечные границы, дуговые названия океанов, свитки городов и карточка легенды `Условные обозначения`.
  - `Style::Painted` — **Живописный атлас**: сочные зелёные луга, лазурный океан с прибрежным мелководьем, мощёные дороги с мостами и пергаментные свитки городов.
- Независимый экспорт в **PNG** и многослойный векторно-растровый **SVG** (с отключаемыми слоями `layer-graticule`, `layer-currents`, `layer-routes`, `layer-frame`, `layer-compass`, `layer-labels`, `layer-legend`).

### `fms-studio` — отдельное локальное приложение и студия (без внешних зависимостей)
- Нативное окно для macOS (`WKWebView` + локальный обработчик схемы `fms://`, без браузера и порта) со сборкой автономного бандла `Fantasy Map Studio.app`, а также резервный HTTP-режим (`--web --port 7878`):
  - параметры планеты земной группы по умолчанию;
  - мгновенное переключение стилей (`Экспедиционный` / `Живописный`) и слоёв SVG;
  - клик-инспектор точки и режим **«Поставить город»** с прокладкой сухопутных дорог по рельефу и перевалам;
  - плавный зум колёсиком с автодетализацией (область перестраивается в высоком разрешении) и сохранение PNG / автономного SVG.

## Проверка и запуск

```bash
cargo test --release
cargo build --release --examples
cargo run --release -p fms-studio
./fms-studio/scripts/bundle_macos.sh
cargo run --release -p fms-studio -- --web --port 7878
cargo run --release -p fms-render --example atlas -- e out_atlas all
cargo run --release -p fms-core --example planet -- a 360
cargo run --release -p fms-core --example region -- a 6
```
