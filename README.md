# Fantasy Map Studio — ядро геологии и воды

Чистый старт проекта на Rust (нулевые внешние зависимости в `fms-core`).
В репозитории оставлены только базовые физические механики планеты: тектоника литосферных плит и глобальная гидросфера.

## Модули `fms-core`

- `tectonic` — сферическая тектоника литосферных плит, движущие силы мантии/хребтов/слэба, столкновения и дуги, изостазия Эйри, тепловое погружение дна, эрозия и уровень моря.
- `currents` — сферический решатель океанических течений (уравнение Стоммела `r∇²ψ + ∂ψ/∂λ = G(φ)`) и прибрежный теплоперенос.
- `climate` — температурное поле и зональный перенос влаги с дождевой тенью для водного баланса бассейнов и стока.
- `hydrology` — открытый океан, заполнение впадин Priority-Flood, стационарный водный баланс озёр/солончаков, порядок Стрелера и дерево рек со сглаживанием.
- `grid` — равнопромежуточная сферическая сетка с замыканием долготы `0 ↔ w - 1`, геодезические расстояния и операторы поля.
- `rng` — детерминированный ГПСЧ и трёхмерный сферический шум.

## Проверка и запуск

```bash
cargo test --release
cargo build --release --examples
cargo run --release --example gen -- a 360
cargo run --release --example sea
```
