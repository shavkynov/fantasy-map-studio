# Fantasy Map Studio

Физически достоверный генератор фэнтези-миров и картографический рендерер на Rust (без внешних крейт-зависимостей в workspace).

## Крейты workspace

### `fms-core` — физическое ядро планеты и мира
- `tectonic` — сферическая тектоника литосферных плит: наследственные древние и молодые швы столкновений (`suture`), раскол континентов, лагранжевы рифты и вулканические провинции, желоба субдукции, упругие предгорные прогибы, изостазия Эйри и сохранение объёма океана.
- `currents` — сферический решатель океанических течений (уравнение Стоммела `r∇²ψ + ∂ψ/∂λ = G(φ)` с учётом скорости вращения `solve_with_rotation`).
- `climate` — сезонные поля температуры (январь/июль), `ClimateParams`, термические муссоны, 2D-полулагранжев перенос влаги с рециклингом и дождевой тенью, Holdridge PET, индекс аридности, снег и ледники.
- `erosion` — склоновая диффузия, флювиальная и ледниковая эрозия (неявный решатель FastScape), отложение аллювия и наращивание дельт.
- `hydrology` — океан, Priority-Flood, водный баланс пресных/солёных озёр и солончаков, сезонный сток (`discharge_jan_m3s` / `discharge_jul_m3s`), пересыхающие русла (`is_wadi`), оазисы, порядок Стрелера и типы берегов.
- `biomes`, `geography`, `resources`, `civilization`, `toponymy`, `planet`, `region` — 19 биомов, ресурсно-торговая иерархическая система поселений (столицы в лучших не-пограничных точках, крупные торговые города на пересечениях маршрутов, обязательный баланс воды/пищи и разнесение городов), дикие/опасные земли (`is_wild`) со стоянками охотников, руинами и пограничными тропами, морские трассы с отступом от берега, русскоязычная топонимика и бесшовный региональный зум `2..=16×`.

### `fms-render` — классический картографический рендерер «от руки» (PNG и SVG)
- Классический стиль линейки 0.89.0: пергаментная бумага с зерном, береговая штриховка воды / три концентрических ореола / гипсометрическая отмывка, мягкая северо-западная светотень рельефа, деликатные горизонтали и увалы, векторные горы с теневой штриховкой, сгруппированные рощи и биомы, реки с мостами, морские пути с подложкой, границы держав, дуговые подписи и легенда.
- Три встроенных стиля в изотропной проекции Паттерсона (без разрезания материков):
  - `Style::Sepia` — **Сепия**: тёплый пергамент, штриховка воды у берегов и архивная тушь.
  - `Style::Ink` — **Ч/Б**: строгий монохром с тремя концентрическими ореолами вокруг суши.
  - `Style::Color` — **Цветной**: мягкая гипсометрическая отмывка рельефа, прибрежный шельф и красные государственные тракты.
- Независимый экспорт в **PNG** и многослойный векторно-растровый **SVG** (слои `layer-rivers`, `layer-water-detail`, `layer-relief`, `layer-forests`, `layer-ice`, `layer-borders`, `layer-roads`, `layer-routes`, `layer-settlements`, `layer-wildsites`, `layer-pois`, `layer-deposits`, `layer-currents`, `layer-labels`, `layer-frame`, `layer-legend`).

### `fms-studio` — кроссплатформенная картографическая студия (macOS arm64/Intel, Windows, Linux)
- Минималистичный интерфейс: генерация государств, городов и дорог по команде пользователя после создания планеты.
- Нативные десктопные окна для **macOS** (`WKWebView` + схема `fms://`, автономный бандл `Fantasy Map Studio.app` для Apple Silicon и Intel) и **Windows** (отдельное окно `WebView2` без консоли и браузера, автономный единый `.exe` со встроенным диалогом сохранения файлов); на **Linux** — встроенный локальный HTTP-сервер с автоматическим открытием в браузере (или headless-режим через `--web` / `--no-browser` / `--port 7878`).
- Интерактивный конструктор дорог «от точки до точки» (поселения, стоянки, геометки, ориентиры) без цветного визуального шума, кликабельные иконки поселений с карточкой ресурсов и плавное углубление в регионы (`2..=16×`).

## Проверка и запуск

```bash
cargo test --release
cargo build --release --examples
cargo run --release -p fms-studio
./fms-studio/scripts/bundle_macos.sh
cargo run --release -p fms-studio -- --web --port 7878
cargo run --release -p fms-render --example atlas -- e out_atlas all
cargo run --release -p fms-core --example planet -- a 360
cargo run --release -p fms-core --example region -- a 6
```
